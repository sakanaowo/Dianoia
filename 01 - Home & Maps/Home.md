## 2. Nhiệm vụ & Hành động (Actionable Tasks)

Hệ thống tự động tổng hợp từ `obsidian-tasks-plugin` qua các ghi chú trong vault:

### Việc ưu tiên & Cần làm hôm nay

```tasks
not done
(due before tomorrow) OR (priority is high)
hide task count
```

### Việc mới ghi nhận từ Inbox

```tasks
not done
path includes 00 - Inbox
hide task count
```

### Nhiệm vụ nghiên cứu theo Lộ trình

```tasks
not done
path includes 06 - Projects
group by filename
```

### Vừa hoàn thành trong 7 ngày qua

```tasks
done after 7 days ago
hide task count
```
